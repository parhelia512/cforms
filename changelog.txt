Version 1.03.0 (15-May-2026)
    Lazy control handle creation has been implemented:
        Previously, users needed to call the createHandle function for Forms and controls. We have removed this redundancy, which solved many design issues and brought more convenience. We can now reduce the number of parameters for constructors. We can now use struct members like properties.

    ListViewSubItem is now a struct.
        I have plans to add aesthetic features to sub items.

    Implemented toStr macro and you can use this to stringify non-string values. This solved ownership problem.
        Note: toStr returns temp allocated string, manage it on your own.

    Removed setter functions for special mouse events like enter, hover & leave.
        From now on, you can simply assign an event handler for these events.

    Improved NumberPicker drawing.
        Previously, NumberPicker's buddy edit border drawing was a workaround. It was unnecessarily complex.
        And it ended up causing unnecessary glitches in the buddy edit.
        Now, the NumberPicker's buddy edit borders are drawn perfectly by handling the WM_NCCALCSIZE and WM_NCPAINT messages.


Version 1.02.0 (26-Apr-2026)
    GroupBox can now act as a parent control (like Form).
    Reduced redundant code using base Control methods.
    Improved mouse events: enter, hover, and leave.
